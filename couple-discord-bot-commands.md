## Daily Rituals & Greetings

### 1. `/gm`
- **Description:** Send a wholesome good morning message
- **Example Output:** "Good morning my love! ☀️ Today is going to be amazing because you're in it. Don't forget to drink water!"
- **Cooldown:** Once per day per user
- **Embed:** Warm sunrise colors (orange/yellow gradient), sun emoji GIF
- **Personal Touch:** Rotates through custom messages you've both added; remembers timezone differences

### 2. `/gn`
- **Description:** Send a calming goodnight message
- **Example Output:** "Goodnight sweetheart 🌙 May your dreams be as beautiful as you are. Sleep tight!"
- **Cooldown:** Once per day per user
- **Embed:** Deep blue/purple night sky colors, moon animation
- **Personal Touch:** Can include a random memory from your relationship

### 3. `/hug [@user]`
- **Description:** Send a virtual hug animation
- **Example Output:** "*wraps arms around @user tightly* 🤗 You're safe and loved!"
- **Cooldown:** None
- **Button Interaction:** "Hug Back" button
- **Embed:** Warm pink/red colors, animated hug GIF

### 4. `/kiss [@user]`
- **Description:** Send virtual kisses
- **Example Output:** "*plants a gentle kiss on @user's cheek* 💋 Love you!"
- **Cooldown:** None
- **Button Interaction:** "Kiss Back" button
- **Embed:** Red/pink colors, kiss mark emojis

### 5. `/cuddle [@user]`
- **Description:** Initiate a cozy cuddle session prompt
- **Example Output:** "*pulls @user close under a blanket* 🛋️ Perfect evening for cuddling with you!"
- **Cooldown:** None
- **Embed:** Cozy warm colors, fireplace or blanket GIF

### 6. `/boop [@user]`
- **Description:** Playful nose boops
- **Example Output:** "*boops @user's nose* 👆👃 Boop! You're adorable!"
- **Cooldown:** None
- **Button Interaction:** "Boop Back" button
- **Embed:** Playful bright colors, cute animal GIF

### 7. `/pat [@user]`
- **Description:** Gentle head pats
- **Example Output:** "*gently pats @user's head* 👋 Good job today, proud of you!"
- **Cooldown:** None
- **Embed:** Soft pastel colors, patting animation

### 8. `/comfort [@user]`
- **Description:** Send comfort messages for bad moods

- **Cooldown:** None

## Implementation Best Practices

### Technical Recommendations:
1. **Database Persistence**: Store all memories, points, and preferences in a database (SQLite, PostgreSQL, or MongoDB)
2. **Cooldown Management**: Use Redis or in-memory caching for cooldown tracking
3. **Embed Customization**: Allow couples to customize colors, emojis, and themes
4. **Privacy**: Ensure all data is private to the server
5. **Backup System**: Regular backups of memories and important data

### Engagement Strategies:
- **Notifications**: Opt-in reminders for daily rituals
- **Streaks**: Visual indicators for consistent usage
- **Surprises**: Random unsolicited positive messages
- **Evolution**: Commands that grow and change with the relationship
- **Personalization**: Learn from usage patterns to improve suggestions
