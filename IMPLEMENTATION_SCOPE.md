# Implementation Scope

## Roleplay infrastructure

The shared roleplay infrastructure applies to every registered action category, including the existing `intimate` category:

- Action registration and lookup
- Existing per-action cooldown handling
- Existing target validation
- Existing GIF lookup
- Existing interaction/XP/affection tracking
- Existing optional pronoun rendering support
- Shared roleplay service execution

## Intimate category

The existing `intimate` action definitions and response content are intentionally **not rewritten or expanded**. No new explicit sexual responses or templates are being generated by this implementation.

The important distinction is that the **shared infrastructure is not category-excluded**: an already-registered intimate action continues to flow through the same roleplay service and cooldown system as other registered actions.

No new explicit sexual commands, sexual templates, or sexual content are added.

## Help documentation

The help command documents supported functionality at a feature/category level without reproducing explicit sexual response text.
